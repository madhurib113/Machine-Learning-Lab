# Experiment 4 – Regression Analysis using Linear and Regularized Models

## Aim

To implement Linear Regression, Ridge Regression, Lasso Regression and Elastic Net Regression for predicting loan amounts and compare their performance.

## Dataset

The loan amount dataset was used for this experiment. It contains numerical and categorical features related to loan applications. The target variable is the loan amount sanctioned. :contentReference[oaicite:0]{index=0}

## Models Used

- Linear Regression
- Ridge Regression
- Lasso Regression
- Elastic Net Regression

## Work Done

- Loaded and examined the dataset
- Handled missing values
- Encoded categorical variables
- Standardized numerical features
- Performed basic EDA
- Visualized feature and target distributions
- Split the dataset into training and testing sets
- Implemented Linear Regression
- Implemented Ridge, Lasso and Elastic Net Regression
- Performed hyperparameter tuning using GridSearchCV
- Used 5-fold cross-validation
- Evaluated the models using MAE, MSE, RMSE and R² score
- Compared model performance and training time
- Visualized predicted and actual values
- Plotted residuals and coefficient comparisons

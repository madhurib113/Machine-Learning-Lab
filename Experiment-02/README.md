# Experiment 2

## Email Spam/Ham Classification using Naive Bayes and KNN

This experiment deals with classifying emails as spam or ham using Naive Bayes and KNN.

### Models Used

- Gaussian Naive Bayes
- Multinomial Naive Bayes
- Bernoulli Naive Bayes
- KNN

### Work Done

- Loaded the Spambase dataset
- Handled missing values
- Normalized the features
- Performed exploratory data analysis
- Split the data into training and testing sets
- Compared the three Naive Bayes models
- Studied the effect of different values of k in KNN
- Used GridSearchCV and RandomizedSearchCV for KNN
- Compared KDTree and BallTree
- Performed 5-fold cross-validation
- Compared training and prediction time
- Evaluated the models using different performance metrics
- Generated the required evaluation plots

### Dataset

Spambase Dataset from Kaggle.

# Experiment 1 – Working with Python Packages

## Aim

To understand the basic use of Python packages used in machine learning and perform basic data analysis and preprocessing.

## Work Done

- Imported and used Python libraries
- Loaded and explored datasets
- Checked dataset structure and data types
- Checked for missing and duplicate values
- Identified numerical and categorical columns
- Performed basic data preprocessing
- Encoded categorical data using LabelEncoder
- Applied feature scaling using StandardScaler
- Applied normalization using MinMaxScaler
- Studied feature selection techniques
- Identified the type of machine learning task for different datasets
- Performed basic exploratory data analysis
- Created histograms and box plots
- Created scatter plots
- Created correlation heatmaps

## Datasets

- Iris Dataset
- Loan Amount Prediction
- Diabetes Prediction
- Email Spam Classification
- Handwritten Character Recognition / MNIST
